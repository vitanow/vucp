# Landing Page Template

## Hero Section
```
# [Headline: Outcome in 5 words]

[Subheadline: How in 1 sentence]

[CTA Button: Action + Benefit]

[Visual: Product or result]
```

## Problem Section
```
## You know when...

[Describe their exact pain vividly]

And then...

[Escalate the pain]

So you end up...

[Show the cost — time, money, stress]
```

## Solution Section
```
## Here's the thing...

[Your approach, different from status quo]

### Instead of [old way], you get [new way]

- [Benefit 1: Specific outcome]
- [Benefit 2: Specific outcome]
- [Benefit 3: Specific outcome]
```

## Social Proof Section
```
## Used by [number] [specific people]

> "[Specific quote about outcome, not product]"
> — [Name], [Role], [Company]

> "[Specific quote]"
> — [Name], [Role]
```

## How It Works Section
```
## How It Works

### 1. [Step 1]
[1 sentence, no jargon]

### 2. [Step 2]
[1 sentence]

### 3. [Step 3]
[1 sentence]

[CTA: Start Now]
```

## FAQ Section
```
## FAQ

### Q: [Real objection 1]
[Direct answer, no corporate speak]

### Q: [Real objection 2]
[Direct answer]

### Q: [Real objection 3]
[Direct answer]

### Q: How do I get started?
[CTA: Start Free Trial]
```

## Final CTA Section
```
## [Same headline as hero]

[Same CTA as hero]

[Optional: urgency or guarantee]
```
