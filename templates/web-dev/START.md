# START HERE — VUCP Web Dev Workspace

## If you are a human

1. Open `CURRENT.md` — this tells you exactly where the project is right now.
2. Open `WORKSPACE.md` — this tells you what this project is and its full tech stack.
3. Drop new tasks or raw material into `_inbox/`.
4. Before any production or database action, check `SAFEGUARDS.md`.

## If you are Claude (AI)

Read these files in this exact order before doing anything:

1. `CURRENT.md` — active feature, last session state, files changed, open blockers
2. `WORKSPACE.md` — project identity, tech stack, conventions, patterns
3. `_delta/ERRORS.md` — mistakes made in previous sessions. Do not repeat them.
4. The current stage `CONTEXT.md` — your specific task contract for this session

**Never modify `_knowledge/` directly. Propose changes via `_proposals/knowledge_updates/`.**

**Protocol:** VUCP v0.4.1 Standard
