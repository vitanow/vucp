# Cross-Project Patterns

This folder is a template for a private cross-project pattern library.

Copy it to:

```text
~/.vucp-user/_cross_project_patterns/
```

Do not use this as a dump of old projects.

Use it only for distilled, reusable patterns with:

- status;
- confidence;
- evidence count;
- applies_to;
- does_not_apply_to;
- source_projects.

## Rule

A VUCP agent may load only a small number of matching confirmed patterns during Full Startup.
