# VUCP Positioning

## One sentence

VUCP is a filesystem protocol that makes AI work inspectable, repeatable, portable, reviewable, and safer.

## Not another AI agent

VUCP does not replace ChatGPT, Claude, Cursor, Codex, Aider, or local models.

It gives them a shared, inspectable workspace structure.

## Why not just Git + README?

Git preserves history. README explains the project.

VUCP adds:

- `CURRENT.md` as operational truth
- `MANIFEST.yaml` as workflow routing
- stage `CONTEXT.md` contracts
- `_delta/ERRORS.md` as reusable failure memory
- `_runs/` as reproducible run history
- `SAFEGUARDS.md` as safety control plane
- `.vucpignore` as intentional context loading discipline
