# Landing Page Audit

## 5-Second Test
Show page to someone for 5 seconds, then ask:
- [ ] What does this product do?
- [ ] Is it for you?
- [ ] Why should you care?

## Conversion Checklist
- [ ] One clear CTA above the fold
- [ ] Headline mentions outcome
- [ ] Social proof within first 2 screens
- [ ] Pricing is visible (or easily accessible)
- [ ] FAQ addresses top 3 objections
- [ ] Mobile CTA is thumb-reachable
- [ ] Page loads in < 3 seconds

## Copy Checklist
- [ ] No jargon or buzzwords
- [ ] Uses customer's language
- [ ] Benefits > features
- [ ] Specific numbers (not "many", "fast")
- [ ] Risk reversal (free trial, guarantee)

## Technical Checklist
- [ ] SSL active
- [ ] Forms work
- [ ] Thank you page after signup
- [ ] Email confirmation sends
- [ ] No broken links
- [ ] Images optimized
- [ ] Core Web Vitals passing
