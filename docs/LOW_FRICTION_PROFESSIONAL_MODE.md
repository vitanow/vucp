# Low-Friction Professional Mode

VUCP is designed so non-professionals can benefit from a professional workflow without learning the whole process.

The user should not need to understand every file.

The system should surface:

- what matters;
- why it matters;
- what to do next;
- what can be approved with one sentence;
- what is blocked.

This is implemented through:

```text
AUTOPILOT.md
_attention/ATTENTION.md
_delta/AUTOPILOT_LOG.md
vucp doctor
vucp autopilot audit
```
