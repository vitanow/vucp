# Stage 4: Landing Page

## 1. Purpose
Създай landing page copy, което продава преди продуктът да е готов.

## 2. Required Context
- `stages/03-solution-design/output/solution-definition.md`
- `/_knowledge/domain/landing-page-psychology.md`
- `/_knowledge/playbooks/landing-page-copy.md`
- `/_knowledge/brand/voice.md`

## 3. Knowledge Context
- `/_knowledge/domain/landing-page-psychology.md`
- `/_knowledge/playbooks/landing-page-copy.md`
- `/_knowledge/brand/voice.md`

## 4. Inputs
- `input/solution-definition.md`
- `input/customer-quotes.md` (optional: real quotes from interviews)

## 5. Allowed Actions
- Write complete landing page copy
- Generate 3 headline variations
- Create FAQ section
- Suggest visuals

## 6. Forbidden Actions
- Do not use buzzwords without explanation
- Do not promise features not in MVP
- Do not ignore brand voice

## 7. Process
1. Review solution definition
2. Extract customer language from interviews
3. Write PASO structure
4. Generate 3 headline options
5. Write complete sections
6. Create FAQ with real objections

## 8. Outputs
- `output/landing-page-copy.md` (complete page)
- `output/hero-section.md` (3 headline variations)
- `output/faq-section.md`

## 9. Verification
- [ ] Headline mentions outcome
- [ ] Problem section uses customer words
- [ ] CTA is one action, low friction
- [ ] No buzzwords
- [ ] Mobile-friendly structure

## 10. Review Gate
"Ето landing page copy-то. Кое заглавие харесвате най-много? [Вариант A] [Вариант B] [Вариант C] [Напиши свое]"
