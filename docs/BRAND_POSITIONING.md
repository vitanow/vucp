# VUCP Brand Positioning

## One-line description

VUCP is a portable AI workspace format that makes human-AI project work inspectable, repeatable, portable, and safer.

## Short public description

Created by **Zahari Vitanov / Vitanow OPS**, VUCP turns a normal project folder into a structured AI workspace with visible state, reviewable memory, run traces, safeguards, and exports for agent tools like Codex, Claude Code, Cursor, and Windsurf.
