# Demo Before Pitch

## Pattern

Before pitching a platform or raising investment, create a working demo and get real validation signals.

## Why

Specs are not enough. A working demo, dry run, paid user, or LOI makes the narrative credible.

## Use When

- preparing investor material;
- launching a marketplace product;
- deciding whether to build platform features;
- validating a new workflow template.

## Do Not Use When

- writing an internal technical note;
- doing early ideation;
- documenting existing work.
