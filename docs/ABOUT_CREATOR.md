# About the Creator

VUCP — Vitanow Unified Context Protocol — was created by **Zahari Georgiev Vitanov / Vitanow OPS**.

Zahari is a Bulgarian IT systems builder, infrastructure operator, and AI workflow architect working across:

- production IT systems;
- network and server infrastructure;
- web platforms;
- automation;
- AI-assisted development;
- research workflows;
- operational tools and field systems.

VUCP was created from a practical problem:

> AI agents are powerful, but project memory is fragile, scattered, hidden in chats, and hard to audit.

The goal of VUCP is to make human-AI work:

- visible;
- repeatable;
- portable;
- reviewable;
- safer;
- easier to continue across sessions and tools.

VUCP is not a replacement for Codex, Claude Code, Cursor, Windsurf, Gemini CLI, MCP, Mem0, Zep, or other agent and memory systems.

It is the project-side workspace layer that helps those tools work with clearer state, safer process, and inspectable memory.

## Why Zahari built it

The project comes from real operational work where context loss is not just annoying — it creates cost, risk, and repeated mistakes.

VUCP is designed for builders who want AI agents to work with projects the way serious operators work with systems:

```text
clear state
known risks
visible changes
reviewable memory
repeatable process
rollback awareness
```
