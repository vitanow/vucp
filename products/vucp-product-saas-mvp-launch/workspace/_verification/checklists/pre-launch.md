# Pre-Launch Checklist

## Product
- [ ] Core feature works end-to-end
- [ ] User can sign up
- [ ] User can pay
- [ ] User can complete core job
- [ ] Mobile responsive
- [ ] No console errors
- [ ] Error messages are human-readable

## Security
- [ ] HTTPS only
- [ ] Environment variables secure
- [ ] Basic auth (no SQL injection, XSS)
- [ ] Rate limiting on auth
- [ ] GDPR compliance (privacy policy, data deletion)

## Analytics
- [ ] Analytics tool active (GA, Plausible, etc.)
- [ ] Key events tracked: signup, payment, core action
- [ ] Dashboard accessible

## Payments
- [ ] Stripe/Paddle connected
- [ ] Test payment successful
- [ ] Refund process documented
- [ ] Invoice/receipt works

## Email
- [ ] Welcome email sends
- [ ] Transactional emails work
- [ ] Unsubscribe link present
- [ ] SPF/DKIM configured

## Support
- [ ] Support email/channel ready
- [ ] FAQ page exists
- [ ] Response time commitment defined

## Launch
- [ ] Landing page live
- [ ] Domain configured
- [ ] SSL certificate active
- [ ] Database backup scheduled
- [ ] Rollback plan documented
- [ ] Team knows roles
- [ ] Crisis communication ready

## Post-Launch Monitoring
- [ ] Uptime monitoring (UptimeRobot, etc.)
- [ ] Error tracking (Sentry, etc.)
- [ ] Alert channels configured
