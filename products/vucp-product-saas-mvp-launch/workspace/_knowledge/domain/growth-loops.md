# Growth Loops

## What is a Growth Loop?
A system where:
1. User does action X
2. Action X creates output Y
3. Output Y attracts new users
4. New users do action X

Not: "We'll run Facebook ads" (linear, expensive)
Yes: "Users invite users" (compound, cheap)

## Types of Loops

### 1. Viral Loop (Product-Led)
**Mechanism:** User uses product → creates visible value → others see → sign up

**Examples:**
- Dropbox: "Share this folder" → recipient sees Dropbox → signs up
- Calendly: "Book a meeting" → recipient sees Calendly → signs up
- Loom: "Watch this video" → viewer sees Loom → signs up

**For your MVP:**
- Does your product create shareable output?
- Can you add "Powered by [YourProduct]" watermark?
- Can users invite teammates naturally?

### 2. Content Loop (SEO)
**Mechanism:** User creates content → content ranks → new users find → create content

**Examples:**
- Reddit: Users post → Google indexes → new users find → post
- Medium: Writers publish → SEO traffic → new writers → publish

**For your MVP:**
- Can users create public pages?
- Can you programmatically generate landing pages?
- Can you rank for "[problem] + solution"?

### 3. Paid Loop (Unit Economics)
**Mechanism:** Revenue → Ads → Users → Revenue → Ads

**Key:** LTV > CAC by at least 3x

**For your MVP:**
- Calculate rough LTV (monthly price × 12 months)
- Test CAC with small ad spend ($100-500)
- Only scale if LTV/CAC > 3

### 4. Sales Loop (B2B)
**Mechanism:** Customer success → Case study → New prospects → Sales → Customer success

**For your MVP:**
- Document first customer wins
- Turn into case studies
- Use for outreach

## Choosing Your First Loop

| Stage | Best Loop | Why |
|---|---|---|
| 0-10 users | Manual outreach | Learn what resonates |
| 10-100 users | Viral or content | Cheap, compound |
| 100-1000 users | Paid (if unit economics work) | Scalable |
| 1000+ users | Multiple loops | Diversification |

## Loop Metrics
Track weekly:
- **Viral coefficient (K):** How many new users does 1 user bring?
  - K > 1 = exponential growth
  - K < 1 = linear growth (need other channels)
- **Cycle time:** How fast does the loop complete?
  - Shorter = faster growth
- **Conversion at each step:** Where do users drop off?
